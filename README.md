# pi-extensions

Runecraft monorepo of extensions for [pi](https://pi.dev).

## Packages

- `packages/pi-tui` — unified, customizable pi TUI (header, footer, editor) combining ideas from several existing pi extensions into one configurable package. See the design recon at [`docs/pi-tui-recon.md`](docs/pi-tui-recon.md) (to be added).

More packages will be consolidated here over time, including `graphify-pi` (currently at [runecraftai/graphify-pi](https://github.com/runecraftai/graphify-pi)).
